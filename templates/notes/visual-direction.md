# Visual Direction

## 1. Aesthetic Rationale
- **Core Stance**: High clarity, functional hierarchy, deliberate density over ornamental fluff.
- **Boldness in One Place**: Let a single signature visual element command attention; keep the surrounding elements disciplined and quiet.
- **Surface Elevation**: Convey depth via clean, high-contrast borders rather than blurry, diffuse drop-shadows.

## 2. Content & Typography Balance
- Every visual device (borders, dividers, eyebrows) must encode structure, not mere decoration.
- Pair a characterful display typeface with an understated, highly legible body face.
