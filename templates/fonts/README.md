# Fonts Directory

Store static font binary files (`.woff2`, `.woff`) in this directory.

## Recommended Fonts
- **Display**: Space Grotesk / Inter / Syne
- **Body**: Pretendard (Korean/English optimized variable font)
- **Mono**: JetBrains Mono / D2Coding

## Web Distribution Note
Always verify web font licensing before embedding binaries in version control.
Use the `.gitignore` exclusion rules for font binaries when consuming fonts via CDN or NPM packages.
